# File-Organizer
Can be used to organize files into subfolders
SCRIPT MUST BE PLACED IN THE SAME DIRECTORY AS FOLDERS FOR IT TO WORK


## Version 1:
This fun little project was created in ITE back in 2023 shortly after learning Python. I decided to make this project during my free time. The code was really messy and cluttered so I decided to use Jupyter Notebook instead of the usual Python script so that the script would be more readable. 

### Running:
Just put the script into the directory you want to organize. 
The first iteration can only be used for [.jpg, .txt, .xlsx] files
